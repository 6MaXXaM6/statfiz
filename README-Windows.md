# Относительная скорость молекул — Windows

Учебная интерактивная презентация по статистической физике. Python-версия
содержит модель двумерного идеального газа, графики распределений и теорию
с формулами, доступными без интернета.

## Запуск готовой программы

1. Распакуйте архив `Relative-Windows-x64.zip` в любую доступную папку.
2. Откройте `Relative.exe` двойным щелчком.
3. Выберите «Презентация» для опыта или «Теория по теме» для объяснений.
   В разделе «Авторы» размещены фотографии Максима, Азамата и преподавателя.

Сборка предназначена для 64-разрядной Windows (x64). Python, Qt и другие
зависимости уже включены в exe; установка и интернет для работы не нужны.
Первый запуск может занять несколько секунд: программа распаковывает
встроенные библиотеки во временную папку пользователя.

## На слабом компьютере

Движение обновляется до 25 раз/с, графики — до 10 раз/с. Расчёт выполняется
короткими порциями, чтобы интерфейс успевал реагировать. В быстром режиме
статистика может набираться медленнее, чем в прошлой версии.

История автоматически схлопывается: старые точки объединяются в интервалы
с сохранением пиков, числа измерений, средних и дисперсии. Уменьшается только
временная детализация старой кривой; гистограммы не обнуляются.

Перетащите ползунок и отпустите: параметр применяется после отпускания.
На паузе изменения видны сразу после применения параметра. При уходе
на другую страницу опыт ставится на паузу. Диапазоны параметров сохранены.
На начальном экране увеличены шрифты; кнопка «Презентация» выделена цветом.

## Управление

- Шрифты подстраиваются под размер окна с учётом масштаба Windows; на небольших
  экранах интерфейс становится компактнее.
- `F11` — переключение полного экрана и окна; `Esc` — выход из полного экрана.
- «Презентация» — опыт запускается автоматически при первом открытии.
- «Пауза» / «Продолжить» — приостановить или продолжить расчёт.
- «Стоп», затем «Старт» — начать новый опыт.
- «Медленно» — наблюдение за движением; «Быстро» — накопление статистики
  по всем молекулам.
- Температура, массы, число молекул и столкновения настраиваются на экране опыта.
- «Теория по теме» — разделы с навигацией и интерактивными примерами.
- «Выход» в главном меню — закрыть программу.

Чтобы сразу открыть программу в окне, выполните в командной строке из её папки:

```bat
Relative.exe --window
```

Модель двумерная: для модуля скорости используется распределение Рэлея.
Различие с трёхмерным газом объясняется в разделе источников теории.

## Сборка из исходников на Windows

Для этой конфигурации используйте Python 3.8.10 x64. Из папки `relative`
выполните в командной строке:

```bat
py -3.8 -m venv .venv-windows
.venv-windows\Scripts\python.exe -m pip install -r requirements-build.txt PyQt5-Qt5==5.15.2
.venv-windows\Scripts\python.exe -m PyInstaller --noconfirm --clean --distpath dist/windows --workpath build/windows packaging/relative.spec
```

Результат: `relative/dist/windows/Relative.exe`. Тексты, SVG-формулы и эмблемы
из `assets` включаются автоматически. Пересборка самих формул для упаковки
не нужна.

## Автоматическая проверка exe

Из папки с готовой программой:

```bat
start /wait "" Relative.exe --smoke-test smoke-test.txt
type smoke-test.txt
```

Успешный результат начинается с `OK` и содержит число столкновений и графиков.
Проверка открывает страницы без видимого окна, выполняет расчёт и завершается.
Папка должна быть доступна для записи отчёта.

## Проверка этой сборки

Сборка от 01.11.2026: Python 3.8.10 x64, PyInstaller 6.22.3, Qt 5.15.2.
57 тестов исходников прошли на macOS, включая изменение размера окна без сброса опыта.
При F11 и изменении окна вместе со шрифтами пересчитываются колонки, отступы
и строки подписей; текущий опыт сохраняется.
Поля графиков учитывают размер подписей осей, индексы и степени.
Компоновка проверена при 1024×640, 1093×614, 1280×720, 1366×768 и 1920×1080. Готовый Windows exe прошёл проверку
в отдельном окружении Wine 11 без установленного Python: открытие всех страниц,
расчёт столкновений и два графика. Все 54 SVG-файла формул включены и сверены
с исходниками. На настоящей Windows эта сборка пока не проверялась.
