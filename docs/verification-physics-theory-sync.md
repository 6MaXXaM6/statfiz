# Проверка трёх исправлений

27 октября 2026. Выполнено для Python-версии `relative`.

## 1. Физика

В тестах энергии используется относительный допуск с `atol=0`; для импульса —
норма ошибки, делённая на сумму модулей импульсов до столкновения. Это исключает
ложный успех из-за сравнения величин порядка 10⁻¹⁹ с абсолютным допуском 10⁻⁸.
Добавлены отрицательные проверки: нулевая/удвоенная энергия, ошибка энергии 0.1%,
ошибка импульса 1% физического масштаба должны отклоняться.

Измерения на фиксированных условиях из тестов:

| Проверка | Результат |
|---|---:|
| Максимальная относительная ошибка энергии за 2000 шагов, seed=3, 150 A + 20 B, массы 20/80, T=400 К | 6.66·10⁻¹⁶ |
| Относительная ошибка энергии одного наклонного удара, массы 10/40 | 1.11·10⁻¹⁵ |
| Нормированная ошибка импульса этого удара | 0 в данном вычислении |
| Тот же удар с начальным нулевым суммарным импульсом | 1.11·10⁻¹⁵ по энергии; 0 по импульсу |

Это проверка конкретных сценариев, не доказательство численной сходимости во всём
диапазоне параметров. Алгоритм физики исправлять для прохождения этих тестов не потребовалось.

## 2. Теория

В меню добавлен раздел 8 «Источники · 2D / 3D». Он содержит библиографическое описание
учебника Вишняковой, Макарова, Поляковой и Чичигиной, печатные страницы и соответствие
страницам скана. Пример 8.5 обосновывает двумерные распределения; пример 8.6 и сложение
дисперсий объясняют √2. Таблица сравнивает энергии, скорости и распределения в 2D/3D.
В предыдущие разделы добавлены указания на основания формул.

Уточнены ограничения модели твёрдых дисков, условность r∝m^(1/3), условия равновесия,
корреляции отсчётов и статистический характер закона 1/√N. Источники доступны внутри
автономного приложения без сети; полный скан учебника в исполняемый файл не включён.
Визуально проверены верх и низ раздела на 1024×768.

## 3. Синхронность

Проверены реальные пути стрелок, координаты текущих точек и линий, числовые подписи,
содержимое гистограммы и индекс подсвеченного столбика. Набор скоростей включает:
(3,4)/(−1,2), масштабированный вариант, отрицательную проекцию и одинаковые скорости
с нулевой относительной скоростью. Проверяются пара, каждая отдельная молекула и энергия.

Воспроизведён и исправлен дефект на паузе: после изменения T стрелки обновлялись,
а число и точка оставались от последнего измерения (447 вместо 689 м/с в сценарии теста).
Теперь мгновенное значение вычисляется из текущего газа. На графике отображается
текущий маркер и при необходимости отрезок скачка; накопленная история и статистический
вес не меняются. Проверены также изменение массы и выбор другой молекулы.

Поворот гистограммы теперь вызывает перерисовку сразу, в том числе на паузе,
с сохранением накопленных данных. Фиктивная подсветка при смене параметров не добавляется.
