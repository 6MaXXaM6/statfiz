# Как устроена программа (для защиты)

Презентация «Относительная скорость движения молекул идеального газа».
C++17 + Qt 5.15 (Widgets). Около 5 600 строк, файлы не длиннее ~320 строк.

## 1. Три слоя, зависимости только сверху вниз

```
pages/   экраны: титул, презентация, теория, авторы     ── собирает из ui/ и model/
  │
ui/      общие виджеты и графики (не знают про страницы) ── рисует то, что даёт model/
  │
model/   физика и статистика, БЕЗ Qt                     ── можно проверить отдельно (tests/)
```

- **model/** — чистый C++: не подключает ни одного заголовка Qt. Поэтому физику можно проверить тестами без окна (`make test`).
- **ui/** — переиспользуемые детали:
  - кнопки и карточки;
  - параметр «движок + число» (`ParamControl`);
  - оси графиков (`PlotBase`).
- **pages/** — только компоновка и связь событий с моделью.

## 3. Что происходит за один кадр

```
QTimer (16 мс)  →  RunControls::frame()  →  сигнал tick(fast, factor)
   →  DemoPage::on_tick
        ├─ Experiment::advance_by(factor)          медленно: часть шага dt за кадр
        │  или advance_for_seconds(0.020)          быстро: сколько успеем за 20 мс
        │     └─ на каждом шаге:  Gas::step(dt)       движение, стенки, удары
        │                         forget(dt)          старая статистика "забывается"
        │                         sample_selected()   отсчёт для выбранной пары
        │                         sample_ensemble()   (быстрый режим) по всем молекулам
        └─ DemoPage::refresh()  →  каждый виджет перерисовывается по новым данным
```

Изменение параметров:
- **T, массы, число столбиков, память** — статистика **не сбрасывается**: гистограммы переносятся на новые диапазоны, а старое постепенно забывается.
- **Число молекул или состав газа** — газ создаётся заново.

## 4. Физика: где какая формула

| Что | Где | Формула |
|---|---|---|
| Радиус по массе | `physics.cpp: radius_for_mass` | r ∝ m<sup>1/3</sup> (размеры на экране показывают отношение масс) |
| Начальные скорости | `Gas::maxwell_velocities` | каждая проекция ~ N(0, kT/m), затем точная подгонка энергии |
| Температура | `Gas::set_temperature` | в 2D на молекулу приходится kT ⇒ E<sub>полн</sub> = N·k·T; все скорости × √(E<sub>нужн</sub>/E) |
| Смена масс | `Gas::set_masses` | v × √(m<sub>стар</sub>/m<sub>нов</sub>): энергия каждой молекулы (и T) сохраняется |
| Упругий удар | `Gas::collide` | v<sub>i</sub> += 2m<sub>j</sub>/(m<sub>i</sub>+m<sub>j</sub>)·(Δv·n)n, v<sub>j</sub> −= 2m<sub>i</sub>/(m<sub>i</sub>+m<sub>j</sub>)·(Δv·n)n; сохраняются импульс и энергия |
| Шаг dt | `Gas::recommended_dt` | быстрая молекула (4σ) за шаг проходит ≤ ¼ радиуса ⇒ dt ∝ 1/√T |
| Время между ударами | `Gas::collision_time` | ν = Σ n<sub>s</sub>·2(r<sub>k</sub>+r<sub>s</sub>)·⟨u⟩, ⟨u⟩ = √(π/2)·√(kT/μ) |
| Модуль скорости | `theory.cpp: pdf` | Рэлей: f(v) = v/σ²·exp(−v²/2σ²), σ² = kT/m |
| Проекция | `theory.cpp: pdf` | Гаусс: f(v<sub>x</sub>) = exp(−v<sub>x</sub>²/2σ²)/(√(2π)σ) |
| Энергия | `theory.cpp: pdf` | f(E) = exp(−E/kT)/kT, ⟨E⟩ = kT, D = (kT)² |
| Относительная скорость | `Experiment::mass(Obj::Pair)` | те же законы с приведённой массой μ = m₁m₂/(m₁+m₂); для одинаковых молекул μ = m/2 ⇒ всё больше в √2 раз |

## 5. Почему сделано так

- **Поиск столкновений «сортировка и проход»** (`find_close_pairs`).
  - Молекулы сортируются по x, каждая сравнивается только с соседями, пока разница по x меньше суммы радиусов.
  - Вместо N² ≈ 90 000 пар при N = 300 проверяется около N·log N.
- **Экспоненциальное забывание** (`Histogram::forget`).
  - Статистика — скользящее окно со временем памяти τ = K·τ<sub>столкн</sub>. После смены T гистограмма сама переходит к новому распределению.
  - K = 300 подобрано тестом: при K = 100 расстояние до теории велико (0.26), при K = 1000 память слишком длинная. Значение меняется полем «Память».
- **Ленивое забывание.**
  - Вместо умножения всех столбиков на exp(−dt/τ) на каждом шаге новые отсчёты добавляются с растущим весом `gain`. Результат тот же, но на шаг уходит одно деление (проверено тестом `lazy_forgetting_matches_explicit`).
- **Перенос столбиков** (`Histogram::rebin`): вес старого столбика делится между новыми пропорционально перекрытию. Поэтому при смене T или числа столбиков статистика не теряется и не появляются пустые «зубцы».
- **Оси графиков фиксированы по теории** (`DemoPage::configure_plots`): во время опыта шкала не скачет. Графики одного вида строятся в общем масштабе, поэтому разницу в √2 видно на глаз.
- **«Схлопывающийся» график времени — корзины min/max** (`TimeSeries`).
  - История хранится в ≤ 4096 корзинах. В каждой корзине: промежуток времени, min, max, последнее значение, число отсчётов, сумма и сумма квадратов.
  - Когда корзины кончаются, соседние сливаются попарно: min из min, max из max, суммы складываются. Память постоянная, добавление отсчёта — O(1).
  - Ничего не теряется: min, max, среднее и σ за любой промежуток точные. Простое прореживание «каждая вторая точка» теряло бы пики.
  - Ось времени всегда от 0 до «сейчас».
  - Рисование (`TimePlot::draw_columns`) идёт по столбцам пикселей: светлая полоса min…max, полоса среднее ± σ и линия среднего, которое колеблется около теории. Всё рисуется прямоугольниками без сглаживания: ≤ 1 мс на кадр, сколько бы ни шёл опыт.
- **Статистика по всем молекулам** (галочка; в быстром режиме включена всегда): в гистограммы идут скорости всех молекул того же сорта. Это та же функция распределения (эргодичность), только набирается в сотни раз быстрее. Поэтому при запуске сразу видно √2.
- **Опыт из лекции 8** («Все одинаковые»): все молекулы летят в одну сторону с |v| = √(2kT/m). Память автоматически 3 столкновения, то есть гистограмма показывает распределение «сейчас», а скорость ×10. Видно, как столкновения (и только они) приводят к распределению Максвелла.

## 6. Вопрос → где смотреть

| Вопрос | Ответ в коде |
|---|---|
| Почему ⟨\|v<sub>отн</sub>\|⟩/⟨\|v\|⟩ = √2? | `theory.h` (шапка), `readouts.cpp: ratio_text`, тест `relative_speed_is_sqrt2_larger` |
| Как считается удар молекул? | `physics.cpp: Gas::collide` |
| Сохраняется ли энергия? | тесты `collision_conserves_energy_and_momentum`, `energy_conserved_over_many_steps` |
| Почему энергия распределена экспоненциально? Почему ⟨E⟩ = kT? | «Теория», раздел 5 (вывод + движок массы, который ничего не меняет); `theory.h`; тест `mean_energy_is_kT_in_equilibrium` |
| Откуда распределение Рэлея? | «Теория», раздел 3 (кольцо 2πv dv) |
| Что будет со смесью разных масс? | `Experiment::mass(Obj::Pair)` → μ; тест `mixture_uses_reduced_mass` |
| Как задаётся температура? | `Gas::set_temperature` |
| Как устанавливается равновесие? (лекция 8) | «Начальные скорости: Все одинаковые»: столбик → Максвелл за ~3 с; без столкновений — нет. `Gas::beam_velocities`, `collisions_enabled`; тест `beam_start_relaxes_only_with_collisions` |
| Как молекула выбирается мышью? | `BoxView::mousePressEvent` → `DemoPage::on_box_clicked` → `Experiment::select` |
| Почему окно подстраивается под проектор? | `style.cpp: init_style` (размер шрифта от экрана), `DemoPage::fit_box` |
| Как проверить, что всё работает? | `make test`, `make layout`, `make linux` / `make windows` (smoke-тест) |
