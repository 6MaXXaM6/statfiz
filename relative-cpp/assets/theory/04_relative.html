Относительная скорость

Для столкновений важна не скорость молекулы сама по себе, а то, как быстро две молекулы сближаются, — относительная скорость

vотн = v1 − v2

Её распределение

Каждая проекция v1,x и v2,x — независимая гауссова величина. Разность независимых гауссовых величин тоже гауссова, а дисперсии складываются:

σотн2 = kT/m1 + kT/m2 = kT/μ,    μ = m1m2 / (m1 + m2)

Значит, vотн распределена по тем же законам (Гаусс для проекции, Рэлей для модуля), только с приведённой массой μ вместо m.

Одинаковые молекулы: множитель √2

При m1 = m2 = m имеем μ = m/2, поэтому все характерные значения больше в √2 раз:

⟨|vотн|⟩ = √2 · ⟨|v|⟩ ≈ 1.414 ⟨|v|⟩

Зачем это нужно

Молекула «заметает» полосу шириной 2(r1 + r2) и движется относительно соседей со скоростью vотн. Поэтому частота столкновений и длина свободного пробега

ν = n · 2(r1+r2) · ⟨|vотн|⟩,    λ = ⟨|v|⟩ / ν

Отсюда множитель √2 в знаменателе формулы для λ.

Попробуйте:

  • при равных массах чёрная кривая |vотн| шире красной ровно в √2 раз;
  • сделайте m2 много меньше m1 — тогда μ ≈ m2, и относительную скорость задаёт лёгкая молекула.

В опыте: графики |vотн| и |v1| рядом, строка под ними показывает отношение средних — ≈ 1.41.
