# Шпаргалка: как быстро что-то поменять

**Порядок всегда один:**
1. Поменять число.
2. Набрать `make run` — программа пересоберётся и откроется в окне. После правки `settings.h` это около 10 с, после одного `.cpp` — около 4 с на быстром компьютере; на ноутбуке может быть медленнее.
3. Посмотреть результат.
4. Если стало хуже, вернуть число. Если запутались — `git checkout -- путь/к/файлу`: файл вернётся к последнему коммиту.

Перед показом проверьте, что ничего не вылезло за экран: `make layout`. Проверяются 1024×768, 1366×768 и 1920×1080.

Размеры на экране задаются в **«базовых шрифтах»** — это высота обычного текста:
- `1.0` — как обычный текст, `2.0` — вдвое крупнее;
- сам базовый размер подбирается под экран (правило — в `settings.h`).

## Почти всё — в `src/settings.h`

| Хочу | Что поменять |
|---|---|
| Всё крупнее или мельче | `FONT_SCALE` (1.15 сейчас; 1.0 — мельче, 1.3 — крупнее) |
| Больше места графикам | `CARD_MARGIN` (поля карточек) меньше; `MIDDLE_MIN` больше |
| Шире подписи в режиме «на весь экран» | `SIDE_STATS_WIDTH` |
| Длиннее или короче стрелки в сосуде | `ARROW_LENGTH` |
| Крупнее векторы на диаграмме «Скорости» | `VECTOR_RADIUS` меньше |
| Другой газ при запуске | `START_TEMPERATURE`, `START_N`, `START_MASS_A`, `START_MASS_B`, `START_N_B` |
| Диапазон температуры | `TEMPERATURE_MIN`, `TEMPERATURE_MAX` |
| Диапазон числа молекул или масс | `N_MIN`, `N_MAX` (не больше `MAX_PARTICLES`), `MASS_MIN`, `MASS_MAX` |
| Число столбиков гистограммы при запуске и пределы | `START_BINS`, `BINS_MIN`, `BINS_MAX` |
| Память статистики (сколько столкновений помнит) | `START_MEMORY`; для опыта «Все одинаковые» — `RELAX_MEMORY` |
| Крупнее молекулы | `R_MAX` (радиус самой тяжёлой, нм) |
| Больше или меньше сосуд | `BOX_SIZE` (нм) |
| Куда летит пучок в опыте «Все одинаковые» | `BEAM_ANGLE` (градусы от оси x) |
| Быстрее или медленнее медленный режим | `SLOW_FACTORS` (шагов за кадр для положений движка), `START_SPEED` |
| Как быстро идёт опыт «Все одинаковые» | `RELAX_SPEED` |
| Плавность анимации | `FRAME_MS` (16 мс ≈ 60 кадров/с) |
| Сколько считать за кадр в быстром режиме | `FAST_BUDGET` (секунд) |
| Не запускать опыт сам при открытии | `AUTOSTART = false` |
| Один график при запуске вместо двух | `START_TWO_PANELS = false` |
| Статистика сначала только по выбранным молекулам | `START_ENSEMBLE = false` |

## Размеры шрифтов, цвета, линии — тоже в `src/settings.h`

| Хочу | Что поменять |
|---|---|
| Крупнее название на титуле, подзаголовок, большие кнопки, эмблемы | `TITLE_FONT`, `SUBTITLE_FONT`, `MENU_BUTTON_FONT`, `EMBLEM_SIZE` |
| Крупнее заголовок вверху страниц | `HEADER_FONT` |
| Крупнее «= 424 м/с» над графиком | `VALUE_FONT`; список величин над графиком — `SELECTOR_FONT` |
| Крупнее среднее и дисперсию под графиком | `STATS_FONT`; в режиме «на весь экран» — `SIDE_STATS_FONT` |
| Крупнее строку «⟨\|vотн\|⟩ / ⟨\|v₁\|⟩ = 1.414» | `RATIO_FONT` |
| Крупнее панель «Газ», кнопки «Старт / Пауза» | `GAS_PANEL_FONT`, `RUN_BUTTON_FONT` |
| Крупнее числа и подписи на осях | `AXIS_NUMBERS_FONT`, `AXIS_LABEL_FONT`; если не влезают — `AXIS_WIDTH`, `AXIS_HEIGHT` |
| Крупнее текст и формулы теории | `THEORY_TEXT_FONT`, `THEORY_FORMULA_FONT` |
| Другой цвет чего угодно | `COLOR_…`: молекулы `COLOR_MOL1/MOL2`, теория `COLOR_THEORY`, столбики `COLOR_BAR`, фон `COLOR_PAGE`… |
| Толще линии | `THEORY_LINE` (кривая теории), `CURVE_LINE` (график во времени), `CURRENT_LINE` (пунктир текущего значения) |
| Выше или ниже ось плотности над кривой | `HIST_HEADROOM` |
| Дольше светится новый столбик | `FLASH_DECAY` ближе к 1 |
| Больше векторная диаграмма | `VECTOR_SIZE`, `VECTOR_MIN_SIZE` |
| Шире список разделов теории | `DRAWER_WIDTH` |

## Остальное — по файлам

| Хочу | Где |
|---|---|
| Вид кнопок, рамок, движков (скругления, толщина рамок) | `src/ui/style.cpp` — таблица стилей в `init_style` (похожа на CSS) |
| Какая величина во втором графике | `src/pages/demo/demo_page.cpp` — `SECOND_PANEL` |
| Расположение колонок (сосуд / графики / настройки) | `src/pages/demo/demo_page.cpp` — строка `hbox({left_, {middle_, 1}, right_}…)` |
| Что стоит под графиками | там же, `middle_ = card(…)` |
| Тексты на титуле | `src/pages/title_page.cpp` — `TITLE`, `SUBTITLE` |
| Тексты теории | `assets/theory/01_model.html` … `07_experiment.html` (обычный HTML) |
| Авторы, фото, руководитель | `assets/authors.json`; фото — в `assets/authors/` и в `resources.qrc` |
| Подписи кнопок | ищите текст: `grep -rn "Добавить" src` |

## Если что-то сломалось

- **Не собирается:** первая строка с `error:` в выводе говорит файл и номер строки. Чаще всего забыта `;` или скобка.
- **Окно вылезло за экран после увеличения шрифта:** `make layout` покажет, на каком шаге и сколько не хватает. Уменьшите `FONT_SCALE` или `CARD_MARGIN`.
- **Физика «сломалась» после правки модели:** `make test` — 17 проверок (энергия, √2, распределения).
