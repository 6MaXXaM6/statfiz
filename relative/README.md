# Относительная скорость молекул — Python

Python + NumPy + PyQt5 + pyqtgraph. Интерфейс, теория и сценарии опыта приведены
к C++-версии из `relative-cpp`.

Тренировка защиты по текущей версии: [сценарии от settings до перемещения блоков Qt](PRACTICE.md).
Перенос построения векторов внутри сосуда разобран отдельно в сценарии 21.

На этом Mac из корня репозитория:

```sh
make -C relative run     # открыть окно
make -C relative test    # модель и сценарии интерфейса
make -C relative layout  # компоновка на трёх разрешениях
make -C relative macos   # самостоятельный файл dist/macos/relative
```

Шрифты подстраиваются под размер окна в логических пикселях Qt, с учётом масштаба Windows. F11 переключает полный экран. Расчёт стартует при первом открытии «Презентации».

## Что было перенесено из C++

| Область | Было в Python | Теперь |
|---|---|---|
| Теория | Одна длинная статическая страница | 7 интерактивных разделов и отдельный раздел источников/2D–3D, выдвижное меню, Назад/Далее; схема удара, живые распределения и набор случайной выборки |
| Начало опыта | Один график, ручной старт | Два графика: относительная скорость и скорость молекулы; автоматический старт |
| Начальные скорости | Только Максвелл | Максвелл или «Все одинаковые»; во втором случае память 3 столкновения и скорость ×10 |
| Столкновения | Всегда включены | Отдельный выключатель; отражения от стенок остаются |
| Статистика | По всем молекулам только в быстром режиме | Отдельная галочка; быстрый режим включает её автоматически |
| История | Прореживание с потерей отдельных пиков | Корзины min/max, числа отсчётов и моментов; полосы размаха и среднего ± σ |
| Переключение темпа | Продолжение старого масштаба времени | История времени начинается заново, гистограммы сохраняются |
| Оформление | Меньший шрифт, другое размещение | Относительные шрифты по размеру окна, компактные карточки, расположение органов управления как в C++ |

Сохраняются различия реализации: Python использует NumPy и pyqtgraph, C++ —
нативные циклы и QPainter. Поэтому мелкие детали осей/стрелок отличаются, а в быстром
режиме C++ успевает считать больше шагов. Случайные положения и скорости при запуске
не совпадают; формулы, единицы измерения и смысл органов управления одинаковы.

## Где смотреть код на защите

- `settings.py` — настройки шрифтов, размеров, газа и темпа опыта.
- `model/physics.py` — массивы положений/скоростей, шаг времени, стенки и упругий удар.
  Qt здесь нет. Внутри модели: нм, пс, м/с, а.е.м., К.
- `model/theory.py` — Рэлей для модуля, Гаусс для проекции, экспонента для энергии;
  относительная скорость использует приведённую массу μ.
- `model/stats.py` — гистограммы с забыванием и история в ограниченной памяти.
- `model/experiment.py` — выбор пары, управление газом и накопление статистики.
- `pages/demo/page.py` — собирает экран и связывает действия пользователя с моделью.
- `pages/demo/run_controls.py` — Старт/Пауза/Стоп, таймер и темп расчёта.
- `pages/theory_page.py`, `pages/theory/` — навигация и интерактивные примеры.
- `assets/theory/01_model.html` … `08_sources.html` — тексты разделов; формулы в тегах `<math>` набраны как дроби с чертой, корни и индексы.
- `pages/theory/formula_browser.py` — отображает готовые SVG из `assets/theory/formulas/`, подстраивая размер под окно. Интернет и LaTeX при запуске не нужны.
- `ui/plots/` — визуализация; графики получают готовые данные модели.

Один кадр: **таймер → шаги Experiment → движение и удары Gas → статистика → перерисовка**.
Длительность кадра в модельном времени задаётся относительно 300 К и при нагреве
не уменьшается. Обычный режим использует регулятор темпа; «Быстро» — постоянный
темп в 10 раз выше стартового и статистику по всем частицам. Безопасный шаг
столкновений по-прежнему зависит от текущей температуры: при нагреве шагов в кадре
становится больше. Расчёт длинного кадра разбит на порции с возвратом в цикл событий;
пауза и смена параметров отменяют его остаток. Масштаб стрелок фиксирован по 300 К,
поэтому их длина растёт с температурой. Стрелки и построение рисуются на общем холсте сосуда, который целиком перерисовывается каждый кадр. Построение при необходимости сдвигается, сохраняя общий масштаб и разность векторов. Выход за чёрную стенку допустим; если целая стрелка частицы или целое построение не помещается на холсте, оно скрывается до возвращения в допустимые размеры, без обрезания и нормирования длины. Числа настройки — в `settings.py`:
`ANIMATION_REFERENCE_TEMPERATURE` и `FAST_FRAME_FACTOR`.

## Проверки физики и синхронности

Энергия проверяется с нулевым абсолютным допуском, импульс — относительно суммы
модулей импульсов частиц до удара (в том числе при нулевом полном импульсе).
Контрольные тесты отклоняют подменённые значения.

Сценарии интерфейса сравнивают реальные пути стрелок, числовую подпись, точку
на временном графике, текущую линию и подсвеченный столбик для заданных скоростей.
При изменении T или массы на паузе текущий маркер обновляется, а измеренная история
и статистический вес не увеличиваются. При повороте распределение рисуется сразу.

В «Теории», раздел 8, доступны библиография, страницы задачника и сравнение 2D/3D.

При изменении формул пересоберите ресурсы: `python tools/render_formulas.py`
из папки `relative` (для этого инструмента нужен `matplotlib==3.7.5`;
в зависимости приложения он не входит). Подписи интерактивных графиков
используют тот же способ отображения.


## Производительность

Для слабых ноутбуков: до 25 кадров движения и до 10 обновлений графиков в секунду,
бюджет одной порции расчёта 8 мс с проверкой между шагами. Полный кадр может
занимать несколько порций; следующий кадр начинается после его завершения. Ползунки применяются после
отпускания. На паузе графики обновляются сразу; при уходе со страницы опыт
приостанавливается. Подробные замеры и ограничения — в
[отчёте о производительности](../docs/performance.md).


## Обновление 4 ноября 2026

Дизайн 4: параметры сверху, сосуд с построением векторов слева, две независимые
панели справа, настройки статистики снизу. «Связать шкалы» включено по умолчанию;
отключение выбирает диапазон каждой панели отдельно, не меняя расчёт и данные.
Лупа не используется. Газовые параметры задаются ползунками и числовыми полями.

История хранит последние `3 * memory_time` пс. За пределами окна удаляются
целые завершённые корзины; одна граничная может частично выходить за окно.
Лимиты 512 корзин и 256 участков графика сохраняются. Гистограммы остаются
независимыми от отсечения истории. Увеличение памяти не восстанавливает
удалённые точки. `TimeSeries.count` — все отсчёты после сброса,
`summary()` — только сохранённая история; `revision` обновляет кэш при отсечении.
